1.1 白昃战略研究院简介

白昃战略研究院是西南政法大学设立的校级科研机构，中文名称为白泽战略研究院，简称BISS。

白昃战略研究院是西南政法大学设立的校级研究机构。研究院依托法学、区域国别学、政治学与国际关系学等学科，聚焦区域国别研究、国际问题研究和国际合作，开展学术研究与政策探索。

研究院关注全球安全治理、国际关系与地区秩序、非传统安全等议题，结合基础研究、应用研究与政策咨询，推进学术交流和国际合作。

研究方向

区域国别研究

关注区域发展、地区秩序与国别问题。

国际问题研究

关注全球安全治理、国际关系与非传统安全。

国际合作

推动国内外高校及研究机构之间的学术交流。
